Reflect on the differences between static and interactive visualizations.
--> Static visualizations are very customizable and can generate high-quality figures
    for reports and presentations. However, they are fixed, thus people cannot interact with the data.
    Interactive visualizations, on the other hand, enable users to zoom, hover over data points for more information, 
    and apply filters. This makes it easy to study data and identify trends or patterns that may not be obvious in a static graphic.
    
Write a short paragraph discussing the advantages of using dashboards for real-time data exploration.
--> One of the primary benefits of dashboards for real-time data exploration is the ability to immediately monitor changes and
    interact with the data using filters and other tools. Dashboards make it easier to assess information as it refreshes, 
    allowing for speedier decision making without the need to prepare new reports. 
    Dashboards make it easier for users to acquire insights by displaying many visualizations in one place.

Explain how interactive tools like Plotly can improve data communication in professional settings.
--> Plotly can make professionals communicate data more effectively by creating more interesting and informative visualizations.
    Its interactive capabilities enable users to dig deeper into data and focus on the information that is most important to them.
    This enables users to better comprehend trends and patterns, resulting in clearer presentations and more successful data-driven decisions.
